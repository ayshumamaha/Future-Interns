# AI Website Copy Generator for Local Businesses

## Project Overview

This project demonstrates the use of Artificial Intelligence to generate professional website copy for local businesses. AI-powered content generation was used to create website-ready content for a premium custom cake and dessert business named Sweet Crumbs Cake Studio.

## Objective

The objective of this project is to use AI tools to generate persuasive and conversion-focused website content including homepage sections, service descriptions, benefits, call-to-action content, and contact information.

## Business Selected

Sweet Crumbs Cake Studio

## AI Tool Used

ChatGPT

## Deliverables

- Homepage Headline
- Subheadline
- About Section
- Services Section
- Benefits Section
- Call-to-Action
- Contact Section

## Technologies Used

- ChatGPT
- Prompt Engineering
- Content Writing
- GitHub
- MS Word

## Outcome

The project successfully generated professional website content that can be used by local businesses to improve their online presence and customer engagement.
