# AI Content Marketing Using UGC Ads

## Project Overview

This project demonstrates the use of Artificial Intelligence to create User-Generated Content (UGC) style advertisements for digital marketing campaigns. AI-generated prompts were used to create hooks, ad scripts, captions, and call-to-action content.

## Objective

The objective of this project is to generate engaging and conversion-focused marketing content using AI tools while understanding prompt engineering and audience-focused advertising.

## Product Selected

HydraGlow Smart Water Bottle

## AI Tool Used

ChatGPT

## Deliverables

- Ad Hooks
- UGC Scripts
- Social Media Captions
- Call-to-Action Lines

## Technologies Used

- ChatGPT
- Prompt Engineering
- Digital Marketing Concepts
- Content Writing
- GitHub
- MS Word

## Outcome

The project successfully generated relatable and engaging UGC-style marketing content suitable for platforms such as Instagram Reels, TikTok, and YouTube Shorts.
